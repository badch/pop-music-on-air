## ✨ 核心功能特色

### 1. 嚴格格式驗證防呆（格式正確才能送出）
- **班級代碼**：嚴格限制如 `701`（7年級1班）、`702`、`803` 格式。未依規則填寫立即出現紅框提示，格式正確時顯示綠色打勾。
- **座號**：限制為兩位數（`01`~`99`）。若學生僅輸入個位數（如 `5`），系統於離開焦點時自動補零為 `05`，避免格式混亂。
- **姓名與全題目必填**：選擇題 5 題、星馬歌手 2 組、社會議題與原因全數填寫後才開放送出。若有漏填，網頁會自動平滑滾動至該題並震動提醒。

### 2. Google 試算表依班級自動分頁
- 當 701 班學生送出時，試算表會**自動建立「701」分頁**。
- 當 702 班學生送出時，自動建立「702」分頁。
- 第一分頁永遠維持「**全校作答總表**」，一覽全校作答情形。
- 每班分頁依照「**座號由小到大自動排序**」，教師批改登記成績極度省心！

### 3. 智慧綜合評分與建議
- **第一大題（牛刀小試，共 50 分）**：
  - 選擇題 5 題，每題 10 分，系統 100% 精準自動計分。
  - 送出後學生立刻可以看到各題解析，立即深化學習概念。
- **第二大題（星馬歌手，共 25 分，每組 12.5 分）**：
  - 內建星馬藝人資料庫（新加坡：孫燕姿、林俊傑、蔡健雅...；馬來西亞：梁靜茹、光良、戴佩妮...）。
  - 自動檢核歌手背景、代表作完整性、以及喜歡原因（是否扣合歌聲、曲風、歌詞、感動與聽歌共鳴）。
  - 自動判定並標註「精熟／完整（11~12.5分）」、「基礎／部分達成（7~10.5分）」、「待加強（0~6.5分）」。
- **第三大題（如果我是歌手，共 25 分）**：
  - 檢核議題明確度（環境生態、校園生活、心理健康、弱勢關懷、土地文化等）。
  - 評估闡述原因之豐富度、生活觀察連結度與反思深度。
  - 自動判定「精熟／深入（21~25分）」、「基礎／清楚（14~20.5分）」、「待加強（0~13.5分）」。
- **滿分 100 分綜合評估**：
  - 自動產出精熟 (A) / 基礎 (B) / 待加強 (C) 評等。
  - 預留「教師覆寫總分」欄位，方便教師人工彈性調整。

## 🚀 老師如何使用？

1. 參考 [`GOOGLE_SHEET_SETUP_GUIDE.md`](file:///h:/我的雲端硬碟/google_AI/reading-coach/流行音樂開麥拉/GOOGLE_SHEET_SETUP_GUIDE.md)，在 Google 雲端硬碟建立一份空白 Google 試算表，貼入 [`Code.gs`](file:///h:/我的雲端硬碟/google_AI/reading-coach/流行音樂開麥拉/Code.gs) 並部署。
2. 開啟 [`index.html`](file:///h:/我的雲端硬碟/google_AI/reading-coach/流行音樂開麥拉/index.html)，點選右上角「⚙️ 試算表連線設定」，貼上取得的 Web App 網址並儲存。
3. 將網址或 HTML 檔案分享給學生，即可開始在課堂或課後讓學生線上作答！
